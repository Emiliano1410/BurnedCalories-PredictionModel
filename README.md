# Regresión Lineal y Random Forest — Predicción de Calorías Quemadas

Proyecto introductorio de la concentración de **Inteligencia Artificial Avanzada para la Ciencia de Datos**.

## Descripción

Este proyecto implementa un modelo de regresión lineal multivariable **sin el uso de frameworks de Machine Learning**, construyendo desde cero las funciones de hipótesis, descenso de gradiente y evaluación (MSE, R²). El modelo se entrena sobre el dataset _Gym Members Exercise Tracking_ para predecir las calorías quemadas durante una sesión de ejercicio, a partir de variables fisiológicas y de la sesión de entrenamiento.

## Contenido del repositorio

Este repositorio incluye únicamente:

- **Códigos fuente** del proyecto en archivos `.py`.
- **Paper** del proyecto en formato `.pdf`, con el reporte completo del análisis, la metodología y los resultados obtenidos.

## Requisitos

- Python 3
- pandas
- numpy
- matplotlib
- scikit-learn
